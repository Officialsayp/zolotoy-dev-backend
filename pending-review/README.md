# На разбор владельцу

Это сохранённые материалы, а не работающая часть zolotoy.dev. Они не подключены
к сборке, активной Bruno-коллекции или GitHub Actions. Автоматического удаления нет.

| Материал | Почему вынесен | Решение владельца |
| --- | --- | --- |
| `echo-gorm/crud.go.exmpl` и `go.mod.txt`/`go.sum.txt` | Отдельный старый CRUD на Echo/GORM; текущий сервер использует net/http. Сохранены исходник и точные зависимости. Пример содержит локальную учебную конфигурацию БД. | Доработать как отдельный эксперимент или удалить |
| `bruno/Create order.yml` | Ожидает 201 без body, но текущий JSON handler возвращает 400 | Переписать как negative test или удалить |
| `bruno/Create order with text.yml` | Старый этап обучения с текстовым body, без assertions | Доработать negative test или удалить |
| `bootstrap/` | Пустой Compose, неиспользуемые Docker/linter настройки и неактивный integration workflow | Вернуть только вместе с настоящей инфраструктурой и тестами |

Для возврата: перенести нужный материал отдельным изменением, адаптировать к текущим
путям и контрактам, добавить проверки. Старые зависимости не возвращать целиком.
Для удаления: просмотреть diff и удалить выбранную папку отдельным коммитом.
Доменные модели Order/Money/OrderItem сохранены в активном `internal/domain`:
это содержательные наработки, хотя HTTP-сценарий пока их не использует.
