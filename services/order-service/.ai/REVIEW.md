# REVIEW.md

Во время code review проверять:

## Handler

Нет ли бизнес-логики.

Нет ли SQL.

Нет ли транзакций.

Передаётся ли Context.

Правильно ли используются HTTP-коды.

Есть ли DTO.

Есть ли обработка ошибок.

Нет ли утечки внутренних ошибок клиенту.

---

## Service

Нет ли зависимости от HTTP.

Нет ли зависимости от transport.

---

## Repository

Работает только с БД.

---

## Общие проверки

- naming

- читаемость

- Go idioms

- SOLID

- DDD

- Clean Architecture

- тестируемость

После каждого ревью обязательно объяснять причины замечаний.
