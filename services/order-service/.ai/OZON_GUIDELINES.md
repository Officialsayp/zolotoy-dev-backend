# OZON_GUIDELINES.md

Во время обучения придерживаться принципов разработки, используемых в крупных Go-командах.

Основные требования:

- тонкие handlers

- бизнес-логика только в service

- repository отвечает только за хранение данных

- явная обработка ошибок

- использование Context

- dependency injection

- интерфейсы определяются рядом с потребителем

- минимальное дублирование

- читаемый код

Если существует несколько решений, объяснить плюсы и минусы каждого.

Не утверждать, что именно так реализовано внутри Ozon.

Использовать формулировку:

"типичный production-подход".
