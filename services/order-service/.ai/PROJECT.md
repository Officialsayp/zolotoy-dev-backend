# Проект

Order Service — первый Go backend в zolotoy-dev-backend для технической консоли
zolotoy.dev. См. [README](../README.md) и [архитектуру](../../../docs/architecture.md).
Продолжаем изучение Service Layer. Содержательные доменные модели сохранены;
их наличие не означает интеграцию с HTTP или готовность всех бизнес-правил.
